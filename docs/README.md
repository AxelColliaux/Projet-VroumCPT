## Quick Start (Development Mode)

### Prerequisites
- Docker + Docker Compose v2
- Python 3.10+
- Java 11+ (for `spark-submit`)
- Apache Spark 3.5 (`SPARK_HOME` set)

### 1. Start the infrastructure

```bash
docker compose up -d
```

Kafka UI will be available at http://localhost:8080.  
Two topics are created automatically: `vehicle-states` and `alerts`.

### 2. Install Python dependencies

```bash
pip install -r generator/requirements.txt
pip install -r streaming/requirements.txt
```

### 3a. Test with socket (no Kafka needed)

Terminal 1 — start generator (stdout):
```bash
python generator/generator.py --no-kafka --rate 5
```

Terminal 2 — pipe to netcat:
```bash
python generator/generator.py --no-kafka --rate 5 | nc -lk 9999
```

Terminal 3 — run Spark streaming:
```bash
spark-submit streaming/streaming_analysis.py \
    --source socket \
    --sink file \
    --output-dir output/alerts
```

Alerts appear as JSON files under `output/alerts/`.

### 3b. Full Kafka flow

Terminal 1 — run generator → Kafka:
```bash
python generator/generator.py \
    --kafka-broker localhost:9092 \
    --rate 10 \
    --error-vehicle-pct 0.3 \
    --high-error-rate 0.7
```

Terminal 2 — run Spark streaming:
```bash
spark-submit \
    --packages org.apache.spark:spark-sql-kafka-0-10_2.12:3.5.0 \
    streaming/streaming_analysis.py \
    --source kafka \
    --kafka-broker localhost:9092 \
    --sink kafka
```

Watch alerts appear in Kafka UI under the `alerts` topic.

### 4. Compute thresholds (batch job)

First, generate some data to a file:
```bash
python generator/generator.py --no-kafka --rate 20 --duration 120 > output/data/sample.json
```

Then run the batch job:
```bash
spark-submit batch/threshold_calculator.py \
    --source files \
    --input-dir output/data \
    --output config/thresholds.json
```

Pass the generated thresholds to the streaming job:
```bash
spark-submit streaming/streaming_analysis.py \
    --source kafka \
    --thresholds config/thresholds.json \
    --sink kafka
```

## How to Add a New Metric

1. In `streaming/streaming_analysis.py`, add a new aggregation DataFrame  
   following the pattern of `compute_metrics()` (returns a DF with columns  
   `window`, `entity`, `error_rate`, `alert_type`).
2. Call `apply_threshold()` and `format_alerts()` on the new DataFrame.
3. Add a new threshold key to `config/thresholds.json` and update  
   `load_thresholds()` to read it.
4. Start a new `write_stream()` query for the new alerts DataFrame.

## How to Add a New Spark Streaming Job

1. Create a new file under `streaming/` (e.g., `streaming_speed_analysis.py`).
2. Reuse the `read_stream()` helper — pass a distinct `--group-id` so the new job
   reads independently (and, in secure mode, add a matching consumer ACL for that
   group in `kafka-init`).
3. Submit with `spark-submit --packages ...` as usual.
